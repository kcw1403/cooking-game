# 개발 기록

유아(만 3세 전후)용 아이패드 놀이 웹앱을 만들면서 진행한 내용, 받은 피드백, QA 결과, 남은 할 일을 정리한 문서입니다.
개발은 Claude Code(AI 코딩 도구)와 대화하면서 진행했습니다. 커밋 단위의 변경 내용은 `git log`에서도 볼 수 있습니다.

## 1. 목표와 원칙

- 아이가 앉아서 집중해서 할 수 있는 **절차형 놀이**를 만듭니다. 예를 들어 샌드위치는 채소 씻기 → 자르기 → 계란 삶기 → 깨기 → 으깨기 → 바르기 → 쌓기 → 먹기 순서로 진행합니다.
- 아이패드에서 손가락으로 조작하고, 가로·세로 화면 모두에 맞춥니다.
- 글을 못 읽는 나이라 모든 안내를 음성으로 읽어 주고, 아이가 머뭇거리면 손가락 힌트로 누를 곳을 보여 줍니다.
- 틀려도 혼내지 않고 다시 해 볼 수 있게 합니다. 실수로 놀이에서 나가지 않도록 막습니다.
- 설치 없이 열리도록 HTML 파일 하나씩으로 만들고, 외부 이미지나 소리 파일을 쓰지 않습니다.

## 3. 피드백과 반영 내용

### 3.1 사용자 입장 QA 1차 (요리·한글)

| 문제 | 반영 |
|---|---|
| 요리 중 🏠을 실수로 누르면 하던 요리가 사라짐 | 요리 중에는 "그만할까요?" 창(⭕ 그만하기 / ❌ 계속하기)을 띄움. 5초 동안 안 누르면 닫히고 이어서 진행 |
| 선택 화면에서 요리 메뉴로 넘어오면 안내 음성이 안 나옴 (iOS는 터치 전에는 소리를 못 냄) | 화면을 처음 만질 때 안내를 읽음 |
| 주먹밥·팬케이크·피자에만 "먹기" 단계가 없음 | 세 요리에 먹기 단계 추가 |
| 한글 놀이터가 3세에게 어려움 (자음 19개, 작은 버튼) | 👶 아기 모드 추가: 놀이 2가지, 보기 2개, 받침 없는 낱말만, 버튼 크게 |

### 3.2 숫자 놀이터 QA

| 문제 | 반영 |
|---|---|
| (버그) "더 적을까요?" 문제를 맞혀도 "많아요"라고 읽음 | 적다 문제에서는 "○ 개가 ○ 개보다 적어요"로 읽음 |
| 아이가 가만히 있으면 아무 반응이 없음 | 8초 뒤 문제를 다시 읽고 누를 곳을 반짝임, 그 뒤 12초마다 반복 |
| 9개와 10개처럼 1개 차이는 눈으로 비교하기 어려움. 두 접시의 줄 수가 달라 헷갈림 | 차이를 2개 이상으로 하고, 두 접시의 한 줄 개수를 같게 맞춤 |
| 처음부터 1~10은 어려움 | 처음 범위를 1~5로 하고, 바꾸면 기억 |

| 세는 그림에 ⭐가 나오면 칭찬 별과 헷갈림 | 세는 그림에서 ⭐를 빼고 🍊로 바꿈 |
| 많다 적다에서 접시 그림을 세어 볼 방법이 없음 | 접시마다 "🔢 세어 볼까?" 버튼 추가. 누르면 그림을 0.7초마다 하나씩 노랗게 표시하며 "하나, 둘…"을 읽고, 끝나면 "○ 개!"를 읽고 버튼에 "🔢 ○개"를 표시함. 별은 주지 않음. 다른 접시를 세거나, 접시를 누르거나, 다음 문제로 넘어가면 세던 것을 멈춤. 8초 동안 반응이 없으면 두 버튼을 반짝임 |

### 3.3 실사용 피드백 11건 (요리 놀이)

| 번호 | 피드백 | 반영 |
|---|---|---|
| 1 | 조리 도구가 미리 떠 있으면 좋겠음 | 도구가 단계 시작부터 재료 옆에 놓여 흔들리고, 만지면 손가락을 따라옴 |
| 2 | 마요네즈 짤 때 숟가락이 보임 | 통을 누르면 통이 그릇 위로 기울며 짜짐, 짜는 동안 숟가락 숨김. 참기름 병도 같은 방식 |
| 3 | 빵에 바를 때 숟가락 대신 버터나이프 | 버터나이프 SVG 그림으로 교체 |
| 4 | 피자 밀대 모양이 이상함 (통나무 이모지) | 손잡이 달린 밀대 SVG 그림으로 교체 |
| 5 | 피자 재료가 통째로 올라감 | 놓으면 썬 조각(버섯, 피망 링, 옥수수 알, 올리브 링, 베이컨, 토마토 슬라이스)으로 올라감 |
| 6 | 토핑 개수를 정하지 말고 버튼으로 넘어가기 | 개수 제한 없음, "✅ 다 올렸어요" 버튼으로 다음 단계 |
| 7 | 김밥이 접시 위에 일자로 놓여 성의 없음 | 둥근 접시에 8조각을 둥글게 담고 단무지 곁들임 |
| 8 | 과일 꼬치 바나나 껍질 벗기기 그림이 허접함 | 휘어진 바나나 SVG, 껍질 세 갈래가 접시 위로 펼쳐지듯 벗겨짐 |
| 9 | 주먹밥 밥 담기는 한 번이면 충분 | 한 번 옮기면 그릇이 가득 차고 다음으로 |
| 10 | 밥알이 격자무늬라 인공적임 (김밥도) | 크기·기울기·위치가 제각각인 밥알을 빽빽하게 흩뿌린 무늬로 교체 |
| 11 | 먹을 때 입 모양으로 조금씩 없어지게 | 누른 쪽 가장자리가 이빨 자국 모양으로 한 입씩 없어짐 (주먹밥, 팬케이크) |

추가로 찾은 버그: 샌드위치 먹기에서 3번 이상 먹은 뒤 힌트 손가락이 이미 없어진 자리를 가리킴 → 남은 부분을 가리키도록 수정.

## 5. 음성 교체 검토 (진행 중)

기기 기본 음성(Web Speech API)은 설정을 바꿔도 기계 느낌이 남아서, 문장을 미리 mp3로 만들어 넣는 방식을 검토하고 있습니다.
게임은 mp3가 있으면 그것을 틀고, 없으면 지금처럼 기본 음성으로 읽도록 바꿀 계획입니다.

| 후보 | 특징 | 비고 |
|---|---|---|
| Microsoft Azure Speech | 공식 클라우드 TTS, 무료 한도 월 50만 자 | 가입·결제 수단 필요 |
| Google Cloud TTS | 공식 클라우드 TTS, Chirp 3 HD 음성 | 가입·결제 수단 필요 |
| 네이버 CLOVA Voice | 한국어 특화 | 유료, 약관 확인 필요 |
| Voicebox (로컬 오픈소스) | 무료, PC에서 실행, 목소리 복제 가능, 로컬 REST API | 설치 용량 큼, 한국어 품질과 모델별 라이선스 확인 필요 |
| 직접 녹음 | 가장 자연스러움 | 문장 수가 많아 시간이 걸림 |

참고: 한국어 TTS 서비스별 점유율은 공개된 신뢰할 만한 자료를 찾지 못했습니다. 그래서 같은 문장을 직접 들어 보고 비교하기로 했습니다.
