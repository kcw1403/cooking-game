# 우리 놀이터

만 3세 전후 유아가 아이패드에서 손가락으로 하는 놀이 모음입니다. 요리 놀이, 한글 놀이터, 숫자 놀이 세 가지가 있습니다.
설치나 로그인 없이 웹 브라우저로 열리고, 모든 놀이가 HTML 파일 하나씩으로 되어 있습니다. 그림, 소리, 음성은 외부 파일 없이 코드로 만듭니다.

- 접속 주소: https://kcw1403.github.io/cooking-game/
- 개발 과정, 피드백, QA 기록: [docs/개발기록.md](docs/개발기록.md)

## 놀이 구성

| 파일 | 놀이 | 내용 |
|---|---|---|
| `index.html` | 놀이 선택 화면 | 요리 놀이, 한글 놀이터, 숫자 놀이 중에서 고르는 첫 화면 |
| `cooking.html` | 요리 놀이 | 샌드위치, 과일 꼬치, 주먹밥, 팬케이크, 피자, 김밥, 과일 스무디 7가지. 씻기, 자르기, 깨기, 바르기, 굽기, 먹기 같은 단계를 아이가 직접 손으로 합니다. 다 만들면 메뉴에 ⭐ 도장이 찍힙니다 |
| `hangul.html` | 한글 놀이터 | 글자 만들기, 듣고 고르기, 따라 쓰기, 그림 단어. 👶 아기 모드(듣고 고르기와 그림 단어만, 보기 2개)와 🧒 언니·형 모드가 있습니다 |
| `numbers.html` | 숫자 놀이터 | 하나씩 세기, 듣고 고르기, 몇 개일까?, 많다 적다. 범위는 1~5 또는 1~10입니다 |
| `index_v1_sandwich.html` | 첫 버전 | 샌드위치 한 가지만 있던 첫 버전 (보관용) |

## 공통 조작

- 🏠 버튼
  - 요리 놀이: 요리 중에 누르면 "그만할까요?" 창이 뜹니다. 요리 메뉴에서 누르면 선택 화면으로 갑니다.
  - 한글·숫자 놀이: 놀이 안에서 누르면 그 놀이의 첫 화면으로, 첫 화면에서 누르면 선택 화면으로 갑니다.
- 아이가 한동안 아무것도 누르지 않으면, 안내를 다시 읽어 주고 누를 곳을 손가락이나 반짝임으로 알려 줍니다.
- 도장, 별, 모드 설정은 기기 브라우저 안(localStorage)에 저장됩니다. 주소가 바뀌거나 브라우저 데이터를 지우면 처음으로 돌아갑니다.
- 음성은 기기에 있는 한국어 음성(Web Speech API)으로 읽습니다. 아이패드는 화면을 한 번 만진 뒤부터 소리가 납니다.

## 아이패드에서 쓰기

1. Safari에서 접속 주소를 엽니다.
2. 공유 버튼 → **홈 화면에 추가**를 누르면 앱처럼 전체 화면으로 열립니다.
3. 새 버전을 배포한 직후에는 GitHub Pages 캐시 때문에 최대 10분 정도 예전 화면이 나올 수 있습니다. 잠시 뒤 새로고침하면 됩니다.

## PC에서 실행하기

HTML 파일을 브라우저로 바로 열어도 대부분 동작합니다. 다만 놀이 사이를 오가는 링크까지 확인하려면 저장소 폴더에서 로컬 웹서버를 띄워 여는 것이 좋습니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. 같은 Wi-Fi의 아이패드로 확인하려면 `--bind 0.0.0.0` 을 붙이고 PC의 IP 주소로 접속합니다.

## 배포

GitHub Pages가 `main` 브랜치의 루트(`/`)를 그대로 배포합니다. 파일을 고친 뒤 커밋하고 push하면 1~2분 뒤 접속 주소에 반영됩니다.

## 기술 메모

- 화면 크기: CSS 단위 `--u: min(1vw, 1vh)`로 가로·세로 화면 모두에 맞춥니다.
- 터치: Pointer Events를 쓰고, 확대·스크롤·길게 누르기 메뉴 같은 iOS 제스처를 막아 둡니다.
- 소리: 효과음은 Web Audio로 합성하고, 음성은 Web Speech API(ko-KR)로 읽습니다.
- 그림: 이모지, CSS 도형, SVG를 씁니다. 바나나, 밀대, 버터나이프, 피자 토핑 조각, 밥알은 SVG로 직접 그렸습니다.
